# Kisan Mitra 1.1.0

The Android app now restores the signed-in experience, resumes partial onboarding, and presents dedicated voice, chat and farm-tool screens with the Mitra companion. Cached content remains visible during refresh failures; background reads prepare frequently visited screens. Offline plain-text chat has explicit pending, syncing and uncertain-delivery states.

Forms protect unsaved edits, focus inline validation errors and support keyboard Next/Done. Shared controls have accessible touch targets, stronger text contrast and reduced-motion behavior. Market prices render before supplementary trend requests finish.

## Deployment

- Android: signed APK, package `com.initio.kisanmitra`, version `1.1.0`, version code `2`. Built against `https://kisan-mitra-api-344920654513.asia-south1.run.app`.
- Backend deployment is required for reviewed starter-plan creation, device-area weather, custom answers to suggested choices, draft-plan counts, and conversation history across renewed sessions. These changes use existing database tables; no schema migration is added in this release.
- Web frontend has no source changes and needs no deployment for this update.
- Publishing this release does not deploy Cloud Run or Firebase Hosting. Until the backend is deployed, the new endpoint-dependent features are not fully available on the hosted service.

## Validation and limits

Flutter analyzer, full Flutter regression suite, populated accessibility/layout scenarios and Android debug build passed during review. The signed release APK passed certificate and version verification; its certificate matches v1.0.0, and all compiled ABIs target the hosted API. All 82 Flutter tests and 459 backend tests passed. Backend tests used dedicated local storage.

Real-phone microphone/TTS latency, physical haptic quality, iOS and new-copy localization remain acceptance checks. Automated speech tests mock native/provider events. Offline task/farm form writes are not supported by the chat outbox. Cached and prefetched content does not guarantee zero waits. Local review prices and station readings were reference records, not verified production observations.
